Topic 1

Tokenization

Segments raw character streams into discrete linguistic sentences and words using NLTK's Punkt tokenizers.

sent_tokenize() & word_tokenize()
Topic 2

Part-of-Speech Tagging

Penn Treebank tagger identifying grammatical roles (NN, JJ, VB) to enable context-sensitive word replacements.

nltk.pos_tag(tokens)
Topic 3

Named Entity Recognition

spaCy convolutional transition-based parser detecting PERSON, ORG, GPE, and DATE targets in real time.

spacy.load('en_core_web_sm')
Topic 4

Text Preprocessing

Lowercasing, regex non-alpha stripping, English stopwords set filtering, and Porter morphological stemming.

PorterStemmer().stem(word)
Topic 5

Vector Space Models

TF-IDF unigram/bigram representation capturing term frequency across the corpus alongside Gensim Word2Vec.

TfidfVectorizer(ngram_range=(1,2))
Topic 6 & 8

Logistic Regression

High-speed binary classification with calibrated probability scores predicting toxicity likelihood in under 3ms.

model.predict_proba(vector)[0][1]
Topic 7: Syntax Parsing

Context-Free Grammar & CYK Chart Parser

Generates structural parse trees verifying grammatical syntax according to formal grammar rules (S -> NP VP).

(S (NP service) (VP (V is) (Adj garbage)))
Topic 8

Dual-Trigger Hybrid Engine

Fuses statistical ML probability classification with deterministic POS-aware dictionary lookups for 0% false negatives.

is_toxic = (prob >= 0.5) or lexicon_hit
Topic 9

Sub-25ms RAM Pipeline

All models, tokenizers, taggers, and vocabularies pre-loaded into module RAM at startup to eliminate disk I/O.

Global RAM Pre-loading (0ms cold start)
🌐 1-Click Production Cloud Deployment

SafeChat NLP is fully packaged for cloud hosting on Render, Railway, Fly.io, or any Docker platform.

1
Deploy to Render (Free Tier):
Create a new Web Service connected to this repository. Set the build and start commands:
Build: pip install -r requirements.txt && python -m spacy download en_core_web_sm && python train_and_syllabus.py Start: gunicorn --worker-class eventlet -w 1 --bind 0.0.0.0:$PORT app:app
2
Deploy via Docker:
Build and run the self-contained container with all NLTK and spaCy models pre-baked:
docker build -t safechat-nlp . docker run -p 5000:5000 safechat-nlp
3
Render Blueprint (`render.yaml`):
The repository includes an infrastructure-as-code render.yaml for automated 1-click provisioning.
⚡ Interactive REST & WebSocket API Hub
GET /ping (Render Cold-Start Wakeup)
curl -X GET http://localhost:5000/ping
POST /api/analyze or /api/test (JSON Pipeline)
curl -X POST http://localhost:5000/api/analyze \ -H "Content-Type: application/json" \ -d '{"message": "Hey John, your update is complete garbage!", "tier": "premium", "sender": "User A"}'
WebSocket Events (Flask-SocketIO)
• connect: Client establishes persistent WebSocket session.
• send_message: Client emits {"sender": "User A", "message": "...", "tier": "premium"}.
• receive_message: Server broadcasts sanitized payload to all connected clients.
• typing: Real-time user typing event broadcast.
